# iced_helper

A small set of components designed to simplify working with Iced. These are primarily UI elements and components that make it easier to work with subscriptions for creating processes that illustrate the progress of their work.

The program provides:
- A system for running multiple identical processes in parallel, with progress display.
- A virtualized list
- A scrollbar
- A parameter alignment system.
- A file input menu
- A number input menu (with the ability to change the actual and displayed numbers)
